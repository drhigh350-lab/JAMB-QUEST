# Compact Interface Assessment — 2026-08-15

Mobile review found that the existing **Practice** tab places the daily mission, comeback narrative, daily-system settings, subject desk, round builder, and topic drill in separate full-width sections. The actions are clear but require prolonged vertical scrolling to reach the study builder.

The existing **Progress** tab exposes its summary, consistency graph, target message, subject signals, history, comparison, revision plan, weak-topic list, saved questions, and badges in one long feed. Its content is useful, but its information hierarchy does not sufficiently prioritise the next action over supporting evidence.

The compact redesign will retain every core feature while reorganising them as focused grouped panels. Practice will foreground the daily mission and use a compact three-card action layout. Progress will foreground the current target, next repair action, and a limited set of expandable evidence panels. The permanent 380 label will be replaced by each learner’s saved target score, or by an invitation to set a personal goal for guests.
