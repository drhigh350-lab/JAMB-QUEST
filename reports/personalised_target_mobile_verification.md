# Personalised target hero verification

On 15 August 2026, two phone-sized preview checks confirmed the target-led hero behaviour. The ordinary preview rendered **380** because the active signed-in preview profile has a persisted target score of 380. The signed-out topic-practice fixture rendered **“Build toward your goal with a system.”**

The hero therefore reads from the learner profile when signed in and uses a neutral guest prompt otherwise. It does not impose a fixed target score on unauthenticated learners.
