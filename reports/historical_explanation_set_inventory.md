# Historical Explanation-Set Inventory

This inventory separates explanation sets by the evidence available in the project rather than assuming that every concise explanation was AI-written.

| Set | Evidence available | Current treatment |
|---|---|---|
| Legacy batches 001–011 | Each batch has a recorded input/output receipt and was processed by the legacy concise-explanation generator. Batch 11 has a separate 20-record apply receipt; batch 12 found no remaining over-cap candidates. | Treated as regenerated explanation batches under the four-line contract. The generator receipts and persisted line-count audits are the release evidence. |
| Active model bank, 1,000 records | Source metadata identifies one original JAMB-aligned practice set, not an official past-question set. It contains no AI-writer identity or generation-run metadata. | Historical AI authorship remains unproven. Eight labels were repaired; 992 explanations were retained; none were withheld. Factual correctness and provenance depth remain owner/source-dependent. |
| Trusted owner-supplied Markdown/DOCX/PDF batches | Source intake receipts identify the supplied source and preserve owner answer keys and explanations where released. | Treated as owner-supplied content, not silently classified as AI-written. Held records remain held when answer keys, options, topics, or explanation constraints fail. |

No explanation set is marked as historically AI-written without a receipt or generator record that supports that classification.
