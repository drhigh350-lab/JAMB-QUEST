# JAMB Quest MVP Scope

JAMB Quest is a **JAMB preparation and CBT simulation platform**. Its product promise is:

> Prepare. Practice. Improve.

The core learner loop is **Practice → Answer → Receive correction → Understand the mistake → Track weakness → Practise the weakness → Improve score**.

## MVP priorities

| Area | Learner outcome |
|---|---|
| CBT simulator | A realistic JAMB exam experience with timing, navigation, flags, calculator, review, and safe interruption recovery. |
| Question practice | Reliable past-question-style practice organized by subject, topic, and difficulty as trustworthy metadata becomes available. |
| Study mode | Immediate correction and explanations without a countdown. |
| Mock exams | Standard full-UTME simulation plus focused subject mocks. |
| Error bank and weakness engine | Exact missed-question recovery and clear evidence of the next weak topic to fix. |
| Performance analytics | Accuracy, pace, subject and topic performance, target-score evidence, and an actionable next step. |
| Study plan | Daily missions generated from real weaknesses rather than generic timetables. |
| Offline readiness | Installable PWA behavior and dependable cached practice access. |

## Learner hierarchy

| Area | Primary purpose |
|---|---|
| Home | Today’s mission, target score, weak areas, and a way to continue. |
| Practice | Quick Study, focused topic practice, past-question practice, and mock CBT. |
| Learn | Topic explanations, flashcards, formulas, and notes only when validated content and metadata support them. |
| Progress | Score, subject performance, topic mastery, mistakes, pace, and target progress. |
| More | Settings, downloads, JAMB information, then admission tools later. |

## Explicitly deferred

AI tutoring, live classes, live teaching, tutor marketplaces, community/chat, and other general-ed-tech features are deferred. They must not dilute the core preparation loop without an explicit user reprioritization.
