# JAMB Quest: Current Feature Inventory

JAMB Quest is currently focused on one job: **serious JAMB preparation and realistic CBT practice**. Its working learner loop is:

> Practice → answer → receive correction → understand the mistake → track weakness → fix the weakness → improve the score.

## What is working now

| Area | Current capability |
|---|---|
| **Installable app** | The app is an installable PWA and works from the website or as an app shortcut. It includes offline caching for the core experience. |
| **Question bank** | **2,577 playable questions** across Use of English, Biology, Chemistry, and Physics. This includes **109 owner-confirmed, keyed The Lekki Headmaster questions** within Use of English. Automatic safeguards still block structurally malformed records from learner cards. |
| **Question experience** | Clean question cards show the subject/topic where it is verified, answer choices, and immediate Study-mode correction. The Lekki direct batch uses the owner-supplied key without inventing a long explanation where one was not supplied. Owner-provided provenance is not shown to learners. |
| **Study mode and topic practice** | Untimed practice with immediate correction. Learners can choose 10, 20, or 40 questions by subject, select a verified syllabus-grounded topic to open an exact 20-question Study drill, or open the visible **The Lekki Headmaster** novel-focus launch from the compact Topic panel. |
| **Single-subject CBT** | Timed CBT practice for any of the four subjects, with 20-, 40-, or 80-question choices. |
| **Full UTME mock** | A standard **180-question** mixed mock: 60 Use of English plus 40 each of Biology, Chemistry, and Physics. |
| **CBT realism** | Countdown, answer flags, pause/resume, calculator, pre-submit review, final answer review, and keyboard shortcuts: A–D, P/N, S, R, Y. Full UTME mocks use direct subject tabs with per-subject answered progress, local question numbering, and subject-specific palettes that distinguish current, answered, unanswered, and flagged questions. |
| **Interrupted CBT recovery** | An unfinished CBT locally preserves answers, flags, current question, and remaining time. The learner can resume or discard it after a refresh or exit. Untimed Study sessions are not treated as resumable exams. |
| **Daily mission** | A learner with no evidence starts a 20-question, four-subject diagnostic—five questions per subject. After evidence exists, the app selects one automatic **20-question weak-topic mission**. |
| **Mistake recovery** | Exact missed questions can be reopened from exam logs. There is also an all-missed recovery action, weak-topic recovery, and saved-question revision. Empty recovery sets never open unrelated questions. |
| **Error bank foundation** | Every completed round saves answer-review evidence. Missed questions are available for exact recovery; full error categorisation is deliberately not yet added. |
| **Progress analytics** | Accuracy, average speed, pace-aware next guidance, round/exam log, subject performance, weak topics, and previous-versus-latest CBT comparison. |
| **Target score** | After a completed 180-question mock only, Progress shows the estimated UTME score out of 400, target gap, and subject contribution accuracy from that same mock. Short practice rounds never create a misleading score projection. |
| **Topic safety** | All **780** formerly placeholder-labelled active records have been resolved to syllabus-grounded topics using the owner-supplied Biology and Chemistry syllabus maps. Topic recommendations and topic practice use only the resulting verified labels. |
| **Daily reminder** | An opt-in daily reminder runs at 7pm UTC. Learners can enable it on a device, send an immediate test from Profile, and a real Android delivery has been confirmed. |

## Current app structure

| Area | Purpose |
|---|---|
| **Practice** | Today’s diagnostic/mission, single-subject Study, verified topic practice, single-subject CBT, and full UTME mock entry points. |
| **Progress** | Performance signals, subject accuracy, weak topics, missed-question recovery, saved revision, and exam history. |
| **Profile** | Learner identity and account-related features. |
| **About** | Product purpose and the “Comeback from Setback / Smashing 380” system. |

## Intentionally deferred

These are deliberately **not** being added yet, so JAMB Quest stays a focused preparation weapon rather than a bloated general ed-tech platform:

- AI Tutor
- Live classes, live teaching, tutor marketplace
- Community and chat
- Video lectures, school finder, and career tools
- Dynamic flashcards, formula vault, rich passage/diagram support, and AI explanation levels
- Topic + difficulty filters and question search, until all topic metadata is trustworthy and the question source is indexable
- Full error classification, until the validated question and analytics model can support it properly

## What trusted metadata will unlock next

Every active placeholder topic has already been resolved through the owner-supplied syllabus maps. Additional dependable metadata—such as difficulty, year, and a suitable index source—must be established before topic-plus-difficulty practice or question search is introduced.
